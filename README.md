# Weronika Czyż – Portfolio / CV

Responsywna strona portfolio i CV wykonana jako projekt zaliczeniowy z Technologii Internetowych na AGH w Krakowie.

## 🇵🇱 Opis

Jednoplikowa strona portfolio pełniąca funkcję interaktywnego CV. Zawiera sekcje z informacjami o wykształceniu, doświadczeniu zawodowym, umiejętnościach oraz projektach studenckich.

### Funkcjonalności
- Animacje wejścia (fade-in w hero, scroll reveal dla pozostałych sekcji)
- Responsywny navbar z hamburger menu na urządzeniach mobilnych
- Płynne przewijanie do sekcji (jQuery)
- Sekwencyjne pojawianie się kart projektów (jQuery `fadeIn`)
- Zegar w stopce w czasie rzeczywistym
- Przycisk powrotu na górę strony
- Klauzula RODO w stopce

### Technologie
`HTML5` `CSS3` `JavaScript` `jQuery 3.7`

---

## Description

A responsive single-page portfolio and CV website built as a university project for the Web Development course at AGH University of Science and Technology in Kraków.

### Features
- Entry animations (fade-in in hero section, scroll reveal for other sections)
- Responsive navbar with hamburger menu on mobile devices
- Smooth scrolling to sections (jQuery)
- Sequential project card appearance (jQuery `fadeIn`)
- Real-time clock in the footer
- Back-to-top button
- GDPR consent clause in the footer

### Technologies
`HTML5` `CSS3` `JavaScript` `jQuery 3.7`
